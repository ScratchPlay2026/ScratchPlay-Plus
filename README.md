# ScratchPlay-Plus

Hello, & welcome to the manual for your ScratchPlay+. We'll take you through all the features your ScratchPlay+ has.

You can play any Scratch game on this virtual console.

You can also listen to music on this virtual console. You can't pause it, but when you start a game, the music stops.

I think that's about it. Enjoy playing on the ScratchPlay+!
